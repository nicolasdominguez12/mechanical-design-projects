# Technical CAD Drawings — Mechanical Design Exercises

This folder contains a set of technical drawings developed in SolidWorks as part of
mechanical design exercises focused on engineering drawing standards, dimensioning,
and manufacturable geometry.

## Scope of Work
- Creation of fully constrained parametric parts
- Application of standard engineering drawing conventions
- Dimensioning, tolerancing, and multi-view layouts

## Tools Used
- SolidWorks (Parts and Drawings)
- Engineering drawing standards

## Objective
Demonstrate proficiency in technical drawing creation, dimensional clarity, and
CAD-based communication of mechanical designs suitable for manufacturing.
